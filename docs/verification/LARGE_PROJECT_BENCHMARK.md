## نطاق التشغيل

أُعيد تشغيل معيار `server/routes/performance.spec.ts` فعلياً في **26 أغسطس 2026، 10:54:19 UTC** مع `KFORGE_RUN_BENCHMARK=1`. أنشأ الاختبار مشروع monorepo مؤقتاً من **5 حزم** و**5,100 ملف مصدر مولد حتمياً**؛ اكتشف الملف التعريفي **5,101 ملف مصدر** (مع ملف اختبار إضافي). مر الاختباران، بما فيهما تحقق صلاحية ذاكرة التخزين المؤقت وتحقق المسار واسع النطاق.

| عنصر الضبط | الدليل الناتج |
|---|---:|
| الحزم المولدة | 5 |
| ملفات المصدر المولدة | 5,100 |
| ملفات المصدر المكتشفة | 5,101 |
| حد رسم المشروع | 2,000 ملف، وحالة التغطية `LIMIT_REACHED` |
| حد مسح الأسرار والاكتمال | 5,000 ملف لكل مسار، وحالة التغطية `LIMIT_REACHED` |
