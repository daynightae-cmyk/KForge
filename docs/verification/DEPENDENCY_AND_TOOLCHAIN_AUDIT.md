# تدقيق الاعتماديات والأدوات المحلي

> **النطاق:** هذا الدليل يصف ما أُجري محلياً على ملف القفل في 26 أغسطس 2026. لا يثبت أمن مزود خارجي أو توقيع حزمة أو خلو بيئة جهاز نظيف من المشكلات.

## نتائج التدقيق

أُجري تدقيقان منفصلان بعد التحديثات: `npm audit --omit=dev --json` لسطح وقت التشغيل، و`npm audit --json` لشجرة التطوير الكاملة. يفصل التقرير عمداً بينهما لأن الاعتماديات التطويرية لا تدخل حزمة تشغيل KNOuX Forge.

| النطاق | الاعتماديات الكلية | حرج | عالٍ | متوسط | منخفض | النتيجة |
|---|---:|---:|---:|---:|---:|---|
| الإنتاج (`--omit=dev`) | 809 | 0 | 0 | 0 | 0 | **PASS** |
| الشجرة الكاملة | 809 | 0 | 0 | 2 | 0 | **مقبول مع حاجز ترقية كبرى موثق** |

تتعلق النتيجتان المتوسطتان المتبقيتان بـ `react-router` و`react-router-dom` ضمن السلسلة 6.x. يحدد التدقيق الإصلاح المتاح بأنه `react-router-dom@7.18.2` ويصنفه كترقية **كبرى**. لم يُستخدم `npm audit fix --force` ولم تُرقَّ السلسلة إلى 7.x بلا مراجعة توافق لتطبيق المنتج. هاتان النتيجتان تطويريتان فقط وفق تدقيق الإنتاج الصفري، لكنهما تظلان ظاهرتين بصدق في التدقيق الكامل.

| المكوّن أو المسار | الحالة قبل التحديث | المعالجة المنفذة | الحالة النهائية |
|---|---|---|---|
| Vitest | ثغرة حرجة مباشرة في الإصدار المحلول | تحديث متوافق إلى 3.2.7 عبر الإصلاح القياسي | لا ثغرة حرجة متبقية |
| Vite وRollup وPostCSS | ثغرات عالية مباشرة أو متعدية ضمن أدوات البناء | تحديثات متوافقة إلى Vite 6.4.3 وRollup 4.63.0 وPostCSS 8.5.26 | لا ثغرة عالية متبقية |
| React Router | نتائج عالية ومتوسطة قبل التحديث | تحديث متوافق داخل 6.x إلى 6.30.6 | نتيجتان متوسطتان فقط؛ الإصلاح الكامل يحتاج 7.18.2 (ترقية كبرى) |
| Picomatch في مسارات Tailwind 3 | ثغرة عالية متعدية في 2.3.1 | تجاوزات مقيدة لمسارات `tailwindcss → chokidar/fast-glob/micromatch` إلى 2.3.2، مع Picomatch 4.0.7 لتوافق Fdir/Vite | لا ثغرة عالية متبقية وشجرة `npm ls` صالحة |
| `@vitejs/plugin-react-swc` | peer غير صالح: الإصدار 3.x يعلن Vite 4/5 فقط | ترقية إلى 4.3.3 الذي يعلن توافق Vite 4–8 | شجرة Vite صالحة |

## سلامة الإجراء

تمت محاكاة الإصلاح أولاً بـ `npm audit fix --dry-run --json`. بعد ذلك شُغّل `npm audit fix` **من دون** `--force`، ثم أُضيفت معالجة Picomatch المقيدة لأن الإصلاح القياسي ترك مسار Tailwind 3 في 2.3.1. بقيت نصوص تثبيت `@swc/core` و`esbuild` محجوبة بموجب سياسة مدير الحزم المحلية ولم تُمنح موافقة تلقائية؛ نجح فحص الأنواع والبناء مع بقائها محجوبة.

## تحذيرات الأدوات وCI

تم تحديث بيانات Browserslist عبر `update-browserslist-db`. أصبح الإصدار المحلول لـ `caniuse-lite` هو `1.0.30001810`، وأعيد بناء المنتج من دون تحذير بيانات Browserslist المتقادمة.

تم تحديث الإجراءات الرسمية في بوابة التحقق إلى `actions/checkout@v7` و`actions/setup-node@v7` و`actions/upload-artifact@v7`، وتحديث checkout في سير عمل SLSA إلى `actions/checkout@v7`. تشرح وثائق checkout وsetup-node الرسمية أن الإصدارات 5 وما بعدها انتقلت إلى Node 24، بينما تستخدم أمثلة upload-artifact الحالية سلسلة 7.[1][2][3] لا يغير التحديث مشغلات البوابة أو اسماء التحف أو فترة الاحتفاظ بها.

بعد تحديث الاعتماديات، شُغّل `npm run typecheck` و`npm run build` بنجاح. كشف تشغيل القبول الكامل مع تتبع الإهمال أن `DEP0190` لم يكن تحذير Playwright بحد ذاته: كان مصدره غلافا التنفيذ المحلي وفحص وقت التشغيل في `server/routes/workspace.ts` عند تمرير أوامر `npm.cmd` عبر `shell: true` على Windows. استُبدل ذلك بتحويل npm-cli إلى عملية Node مقيدة مع `shell: false`، ثم مر قبول أدوات المطور مع `NODE_OPTIONS=--trace-deprecation` من دون إعادة ظهور التحذير. لا توجد آلية كتم أو تجاهل مضافة للتحذير.

## الأدلة المصدرية

لا تُتبع ملفات JSON الخام للتدقيق لأنها تحمل مسارات محلية ولقطات وقتية. القيم المنظمة أعلاه مشتقة من التشغيل المحلي التالي:

| الأمر | الدليل |
|---|---|
| `npm audit --omit=dev --json` | صفر ثغرات إنتاجية |
| `npm audit --json` | نتيجتان متوسطتان فقط تتطلبان React Router 7.x |
| `npm ls picomatch --depth=4` | Picomatch 2.3.2 محصور في فروع Tailwind، و4.0.7 لفروع Vite/Fdir |
| `npm run typecheck && npm run build` | اجتياز بلا تحذير Browserslist متقادم |
| `npx playwright test tests/e2e/developer-git-surface-evidence.spec.ts --workers=1` مع `--trace-deprecation` | تنفيذ أوامر npm وفحص وقت التشغيل محلياً بنجاح من دون `DEP0190` بعد إصلاح الغلاف |
