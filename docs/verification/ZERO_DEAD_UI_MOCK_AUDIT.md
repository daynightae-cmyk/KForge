# تدقيق الواجهات الميتة ومصادر البيانات الوهمية

**تاريخ التدقيق:** 26 أغسطس 2026

**النطاق:** مسارات الإنتاج في `client/App.tsx`، وسطح `KForgeWorkspace`، وواجهات ومسارات الخادم المشتركة.

**منهج التدقيق:** بحث ثابت منضبط عن `mock` و`fake` و`dummy` و`placeholder` و`TODO` و`not implemented` مع استثناء `node_modules` والاختبارات والـfixtures والمخرجات المولدة. جرى بعد ذلك تتبع كل تطابق إلى مسار إنتاج فعلي أو إلى سياق محلل/اختبار/مكوّن غير موجه. لا يُعد التطابق النصي وحده دليلاً على واجهة ميتة.

> **حكم التدقيق:** لا يوجد سطح قابل للوصول من مسارات KForge المنشورة يعرض نجاحًا أو مزودًا أو تنزيلًا أو مراجعة أو حالة CI مصطنعة. توجد مكونات محرر فيديو قديمة ذات محركات وهمية في المستودع، لكنها غير مستوردة في `client/App.tsx` وليست لها route، ولذلك لا تدخل في حزمة أو سطح KForge المنشور. بقيت موثقة كدين تقني معزول بدل حذفها آليًا.

## مسارات الإنتاج الفعلية

| المسار | المكوّن | النتيجة |
|---|---|---|
| `/` | `KnouxForgeInstallation` | نقطة الدخول/التثبيت فقط. لا يستورد محرر الفيديو أو محركاته. |
| `/workspace` | `KForgeWorkspace` | سطح المنتج الفعلي؛ كل حالة معروضة تأتي من API محلي أو من حالة عدم إتاحة صريحة. |
| `*` | `NotFound` | مسار خطأ صريح. |

## تصنيف نتائج البحث

| الموقع | التصنيف | الحكم | سبب القرار والإجراء |
|---|---|---|---|
| `client/pages/KForgeWorkspace.tsx` | **مدخلات واجهة طبيعية** | مقبول | `placeholder` موجود في حقول إدخال فقط (بحث Online Hub، تحليل الأثر، الفلاتر، فتح/استنساخ مشروع، ورسائل commit). لا يحدد حالة منتج أو مصدر بيانات. |
| `client/components/ui/{command,input,select,textarea}.tsx` و`client/global.css` | **بنية UI مشتركة** | مقبول | تطابقات `placeholder` تخص خصائص CSS/HTML القياسية ولا تنتج بيانات أو نجاحات. |
| `server/routes/workspace.ts` | **محلل أدلة حقيقي** | مقبول ومطلوب | مصطلحات `TODO` و`mock` قواعد فحص محلية تكتشف مؤشرات عدم الاكتمال في مشروع مفتوح. النتائج تسجل مصدرًا وrule ومستوى ثقة واقتراحًا، ولا تدعي اكتمالًا أو نجاحًا. |
| `shared/workspace.ts` | **عقد تشخيص وحالة عدم إتاحة** | مقبول | فئة `mock` تستخدم لتصنيف نتيجة الفاحص، و`Keyboard Shortcuts: UNAVAILABLE` يصف بصدق أن محرر الاختصارات غير منفذ؛ لا توجد دلالة مكتملة زائفة. |
| `client/pages/KForgeWorkspace.spec.ts` و`server/**/*.spec.ts` | **اختبارات فقط** | خارج نطاق الواجهة المنشورة | تطابقات fixtures واختبارات رفض `Fake panel` لا تدخل في البناء الإنتاجي. |
| `client/pages/KnouxVideoEditor.tsx` و`client/components/knoux/{KnouxClipAIControls,KnouxSidebar,KnouxTimeline,KnouxInspectorPanel}.tsx` و`client/lib/engineInterfaces.ts` | **مكوّنات قديمة غير موجهة** | دين تقني معزول، غير محمل في KForge | تحتوي محرك `MockVideoEngine` وتعليقات dummy/mock فعلية. `client/App.tsx` لا يستوردها ولا يعرّف route لها؛ البحث عن `KnouxVideoEditor` لا يعثر على استخدام خارج الملف. لا يجوز تسميتها قدرة KForge أو حذفها ميكانيكيًا ضمن مهمة منتج KForge. |

## تحقق السلوك المرئي

| مجال | الضبط المتحقق | النتيجة |
|---|---|---|
| Online وGitHub وCI | الحالات المتصلة تعرض `NOT_CONFIGURED` أو `OFFLINE` أو `BLOCKED` أو `UNAVAILABLE` حتى وجود سياسة/اعتماد/دليل حقيقي. | لا نجاح بعيد مصطنع. |
| Git المحلي | status وملفات الفهرس والتجهيز والإلغاء والإيداع تصدر من Git محلي فعلي؛ الإيداع يتطلب ثقة وتأكيدًا ويعلن `Remote push: NOT_PERFORMED`. | لا أثر push مزيف. |
| Release Gate وArtifacts | SOURCE وLOCAL وPREVIEW وDESKTOP وWINDOWS_PACKAGE وINSTALLER وGITHUB وCI وREMOTE أدلة منفصلة. SHA المحلي لا يستبدل هوية artifact في CI. | لا دمج أو ادعاء CI. |
| Marketplace وPreview | الحالات تستند إلى lifecycle محلي أو نتيجة عدم إتاحة/حظر واضحة؛ لا تقييمات أو تنزيلات أو مزودين مولدين. | لا مقاييس سوقية مصطنعة. |

## القرار والمتابعة

لا توجد إزالة نصية تلقائية، لأن حذف لغة الفاحص أو خصائص `placeholder` القياسية سيخفي دليلًا تشغيليًا صحيحًا أو يضر قابلية الاستخدام. يجب أن يظل أي عمل مستقبلي على محرر الفيديو منفصلًا ومصحوبًا بقرار منتج صريح: إما توجيهه وربط محركاته الحقيقية، أو نقله إلى مشروع مستقل. لا يغير هذا التدقيق حالة تكاملات GitHub والموفرين والتوقيع وSmartScreen وبيئة Windows النظيفة؛ فهي عوائق خارجية أو أدلة منفصلة وليست نجاحات محلية قابلة للادعاء.
