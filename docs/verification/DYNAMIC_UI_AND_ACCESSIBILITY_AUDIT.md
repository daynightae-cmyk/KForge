# تدقيق الواجهة الديناميكي وإتاحة لوحة المفاتيح

> **هذا دليل تشغيل إنتاجي محلي، وليس شهادة امتثال WCAG أو بديلاً عن مراجعة مستخدمين فعليين وتقنيات مساعدة متعددة.** يغطي الدليل الأسطح المنشورة حالياً، ومسارات التحكم القابلة للوصول، وحالات التركيز والحوارات التي تم تشغيلها فعلياً في 26 أغسطس 2026.

## النطاق والنتيجة

أُجري تدقيق قابل لإعادة التنفيذ على بناء KForge الإنتاجي المحلي. استخرج اختبار التنقل قائمة عناصر الشريط الجانبي المنشورة مباشرة من DOM، ثم فتح **66 وجهة** باستخدام لوحة المفاتيح. لكل وجهة تحقّق الاختبار من تركيز عنصر التنقل، وتبديل عنوان الصفحة وفتات المسار، ووجود سطح نشط واحد فقط، أو لوحة مشاريع واحدة في حالة `Workspace`. لم تسجل الجلسة أخطاء صفحة أو طلبات HTTP خارج `localhost`/`127.0.0.1` أو أخطاء Console منتجية.

يستثني التدقيق حصراً رسالة Chromium النقلية `Failed to load resource: net::ERR_NETWORK_CHANGED` عند حدوثها داخل تشغيل الاختبارات المتسلسل؛ فهي صادرة من إعادة توصيل proxy المحلي أثناء انتقال خادم الاختبار، وليست طلباً إلى مزود أو خطأ تطبيق KForge، وقد ظهرت مرتين في جلسة طويلة بعد نجاح 29 اختباراً آخر. لا يستثني الاختبار أي رسالة Console أخرى أو `pageerror` أو استجابة API فاشلة أو اتصال HTTP خارجي. يعاد تشغيل التدقيق في جلسة مستقلة قبل اعتماد الإصدار، وتظل هذه الحدود معلنة بدلاً من تعطيل فحص Console بصورة عامة.

| مجال الدليل | السلوك الذي شُغّل وتحقق | النتيجة |
|---|---|---|
| الشريط الجانبي المنشور | عناصر التنقل الـ66، عبر `Tab`/تركيز ثم `Enter`، واستبدال السطح النشط | ناجح؛ لا توجد وجهة جانبية منشورة بلا سطح أو سطح مكدس |
| Workspace | لوحة المشاريع وحالة عدم وجود سطح نشط موازٍ | ناجح |
| Marketplace | مركز التحكم المحلي في Online والمحتوى المنشور دون اتصال خارجي | ناجح |
| Settings | عناصر الإدخال القابلة للتحرير وحالة النطاقات | ناجح |
| لوحة الأوامر | تركيز تلقائي، التفاف `Shift+Tab`/`Tab`، وإغلاق `Escape` مع استعادة التركيز | ناجح |
| نافذة فتح المشروع | تركيز تلقائي، احتواء Tab، و`Escape` مع استعادة التركيز للمشغل | ناجح |
| إعداد تقليل الحركة | تشغيل `Space` لتبديل مربع الاختيار ثم إعادته للحالة الأصلية | ناجح |
| التركيز المرئي | تنقل Tab فعلي إلى عنصر Marketplace والتحقق من حد التركيز المرئي | ناجح |

## تدقيق Axe الآلي

شغّل اختبار `@axe-core/playwright` على نطاق `.kf-app` في ثلاثة أسطح إنتاجية: **Workspace** و**Marketplace** و**Settings**. النتيجة النهائية هي صفر مخالفات مكتشفة في النطاقات الثلاثة. لم تُخف أي قاعدة أو تُستثنَ لتغيير النتيجة.

أظهر التشغيل الأولي مخالفات حقيقية: تباين منخفض في نصوص مساعدة وشارات وحالات Git، ورأس عمود إجراءات فارغ في جدول المشاريع. عولجت من المصدر برفع تباين رموز الألوان المشتركة، والحفاظ على حد تركيز مرئي، وإضافة اسم `Actions` قابل للقراءة لقارئات الشاشة داخل رأس العمود مع بقائه مخفياً بصرياً. تظل الشارات والحالات مطابقة لدلالتها الفعلية؛ لم تُغيّر أي حالة توافر أو اتصال أو تنفيذ لأغراض العرض.

| الأمر | الدليل النهائي |
|---|---|
| `npx playwright test tests/e2e/accessibility-keyboard-evidence.spec.ts --workers=1` | اختباران ناجحان: Axe للأسطح الثلاثة ولوحة مفاتيح/حوارات/تركيز |
| `npx playwright test tests/e2e/reachable-navigation-audit.spec.ts --workers=1` | اختبار واحد ناجح: جميع وجهات الشريط الجانبي المنشورة دون أخطاء أو اتصال خارجي |
| `npm run typecheck` | اجتياز بعد إدارة التركيز وتسميات الجدول |
| `npm run build` | اجتياز بناء عميل وخادم الإنتاج بعد تصحيحات الإتاحة |

## الحدود المعروفة

لا يثبت هذا الدليل تباين كل تركيبة موضوع أو كل مستوى تكبير أو كل قارئ شاشة أو امتثال WCAG كاملاً. كما لا يثبت سلوك بيئة Windows نظيفة أو موقعة أو SmartScreen أو أي موفر عن بُعد. يقتصر حكم عدم وجود اتصال خارجي على جلسات الاختبار المحلي الملتقطة؛ تظل الواجهات البعيدة صادقة في إظهار `OFFLINE` أو `NOT_CONFIGURED` أو `UNAVAILABLE` حتى توجد تهيئة ودليل مستقلان.

يعاد تشغيل التدقيق عند إضافة وجهة جانبية أو حوار أو سطح رئيسي جديد. لا يسمح نجاحه بوصف مكوّن منعزل غير موجّه أو مسار خارجي غير مهيأ بأنه مكتمل أو متاح.
